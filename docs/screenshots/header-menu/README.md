# Header account menu: screenshots (#67)

Screenshots of the header account menu from PR #67 (`feature/header-profile-menu`, commit f6d027c). They were made in real Edge against the app built from that commit, with a throw-away local database, fake people and a local copy of the techytree.in homepage. They were first kept on the branch `assets/header-menu-screenshots`; they live here so they stay with the repository.

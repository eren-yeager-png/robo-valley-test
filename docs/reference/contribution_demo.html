RoboValley – Contributions Management

Only an Admin can publish, and publishing updates the public Community Ideas page.
1. Contributor submits idea→2. Moderator verifies (approve as-is or edit)→3. Publishing request to Admin→4. Admin opens publish preview→5. Admin publishes→6. Community Ideas updates
